# Perfil: web

Vale para sites, landing pages e páginas de produto.

## Leis prioritárias

| ID | Lei | Limiar neste perfil |
|----|-----|---------------------|
| L01 | Proximidade | Ver G01 |
| L04 | Região comum | Ver G04 |
| L07 | Continuidade | Ver G07 |
| L08 | Efeito Von Restorff | 1 elemento em destaque por seção |
| L09 | Atenção seletiva | Conteúdo obrigatório fora de banners e carrosséis automáticos |
| L14 | Lei de Jakob | Logotipo no topo à esquerda; navegação no topo ou à esquerda |
| L16 | Lei de Hick | 1 CTA primário por seção |
| L17 | Sobrecarga de escolha | Tabelas de planos com 3 ou 4 opções e 1 recomendada |
| L18 | Lei de Fitts | Mínimo de 24×24 px; recomendado 44×44 px |
| L19 | Limiar de Doherty | Retorno visual em menos de 400 ms |
| L21 | Lei de Parkinson | `autocomplete` em todos os campos de dados pessoais |
| L29 | Lei de Murphy | Formulários e listas têm os estados vazio, carregando, erro e sucesso |

## Limiares transversais

| Tema | Limiar | Fonte |
|------|--------|-------|
| Contraste de texto normal | 4,5:1 | WCAG 2.2, 1.4.3 (AA) |
| Contraste de texto grande (24 px, ou 18,66 px em negrito) | 3:1 | WCAG 2.2, 1.4.3 (AA) |
| Contraste de componentes e gráficos | 3:1 | WCAG 2.2, 1.4.11 (AA) |
| Animação automática com mais de 5 s | Precisa de controle para pausar | WCAG 2.2, 2.2.2 (A) |
| Flashes | No máximo 3 por segundo | WCAG 2.2, 2.3.1 (A) |
| Redução de movimento | Toda animação não essencial respeita `prefers-reduced-motion` | Boa prática; WCAG 2.2, 2.3.3 (AAA) |
| Duração de microinteração de UI | 150 a 300 ms | Heurística |
| Duração de transição de tela | 300 a 500 ms | Heurística |
