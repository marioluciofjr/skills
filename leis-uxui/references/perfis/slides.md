# Perfil: slides

Vale para decks, pitches e apresentações de reunião.

## Leis prioritárias

| ID | Lei | Limiar neste perfil |
|----|-----|---------------------|
| L01 | Proximidade | Ver G01 |
| L02 | Semelhança | Ver G02 |
| L04 | Região comum | Ver G04 |
| L08 | Efeito Von Restorff | 1 elemento em destaque por slide |
| L11 | Lei de Miller | Blocos de 3 a 5 itens quando a pessoa precisar lembrar |
| L12 | Carga cognitiva | 2 famílias tipográficas no deck inteiro |
| L15 | Coerência e redundância | Título em forma de afirmação; no máximo 3 blocos de apoio por slide |
| L22 | Efeito de posição serial | Mensagem principal no primeiro ou no último slide |
| L23 | Regra do pico-fim | O deck tem um slide de pico e um encerramento com chamada ou síntese |
| L26 | Navalha de Occam | Remova todo elemento que não muda o entendimento do slide |

## Limiares transversais

| Tema | Limiar | Fonte |
|------|--------|-------|
| Contraste de texto normal | 4,5:1 | WCAG 2.2, 1.4.3 (AA) |
| Contraste de texto grande (24 px, ou 18,66 px em negrito) | 3:1 | WCAG 2.2, 1.4.3 (AA) |
| Contraste de componentes e gráficos | 3:1 | WCAG 2.2, 1.4.11 (AA) |
| Animação automática com mais de 5 s | Precisa de controle para pausar | WCAG 2.2, 2.2.2 (A) |
| Flashes | No máximo 3 por segundo | WCAG 2.2, 2.3.1 (A) |
| Redução de movimento | Toda animação não essencial respeita `prefers-reduced-motion` | Boa prática; WCAG 2.2, 2.3.3 (AAA) |
| Duração de microinteração de UI | 150 a 300 ms | Heurística |
| Duração de transição de tela | 300 a 500 ms | Heurística |

## Observações

- Os limiares de animação valem só para slides animados.
- Texto sobre foto precisa de sobreposição escura ou clara (G08).
